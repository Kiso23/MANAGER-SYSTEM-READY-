================================================================================
                    DATABASE_URL - QUICK REFERENCE
================================================================================

📊 DATABASE_URL FORMAT
================================================================================

postgresql://username:password@host:port/database_name

Example:
postgresql://taskuser:mypassword123@db.example.com:5432/task_manager

Components:
├─ postgresql:// - Protocol
├─ taskuser - Username
├─ mypassword123 - Password
├─ db.example.com - Host
├─ 5432 - Port (default for PostgreSQL)
└─ task_manager - Database name

================================================================================
                    RENDER - GET DATABASE_URL
================================================================================

1. Go to https://render.com dashboard
2. Click "New +" → "PostgreSQL"
3. Configure:
   ├─ Name: task-manager-db
   ├─ Database: task_manager
   ├─ User: taskuser
   ├─ Region: Choose closest
   └─ Plan: Free
4. Click "Create Database"
5. Wait 2-3 minutes
6. Go to PostgreSQL service
7. Click "Info" tab
8. Copy "Internal Database URL" or "External Database URL"

Example Render DATABASE_URL:
postgresql://taskuser:abc123def456@dpg-abc123.render.com:5432/task_manager

================================================================================
                    RAILWAY - GET DATABASE_URL
================================================================================

1. Go to https://railway.app dashboard
2. Click "New Project"
3. Select "Provision PostgreSQL"
4. Railway creates PostgreSQL automatically
5. Click on PostgreSQL service
6. Click "Variables" tab
7. Copy DATABASE_URL value

Example Railway DATABASE_URL:
postgresql://postgres:password@containers.railway.app:5432/railway

Note: Railway auto-links PostgreSQL to backend service!

================================================================================
                    AWS RDS - GET DATABASE_URL
================================================================================

1. Go to AWS Console
2. Search for "RDS"
3. Click "Create database"
4. Configure:
   ├─ Engine: PostgreSQL
   ├─ Version: 15.x
   ├─ DB instance identifier: task-manager-db
   ├─ Master username: taskuser
   ├─ Master password: Generate strong password
   ├─ DB name: task_manager
   └─ Publicly accessible: Yes
5. Click "Create database"
6. Wait 5-10 minutes
7. Go to RDS Dashboard
8. Click on your database
9. Find "Connectivity & security" section
10. Get Endpoint, Port, DB name, Username

Build DATABASE_URL:
postgresql://taskuser:your-password@task-manager-db.abc123.us-east-1.rds.amazonaws.com:5432/task_manager

================================================================================
                    TROUBLESHOOTING
================================================================================

Connection Refused:
├─ Check host is correct
├─ Check port is correct (usually 5432)
├─ Check database is running
├─ Check firewall allows connection
└─ Check credentials are correct

Authentication Failed:
├─ Check username is correct
├─ Check password is correct
├─ Check special characters are URL-encoded
└─ Reset password in platform dashboard

Database Not Found:
├─ Check database name is correct
├─ Create database if it doesn't exist
└─ Check you have permission

SSL Connection Error:
├─ Add ?sslmode=require to connection string
├─ Or add ?sslmode=disable for testing only
└─ Check SSL certificate is valid

================================================================================
                    SPECIAL CHARACTERS IN PASSWORD
================================================================================

If password contains special characters, URL-encode them:

@ = %40
# = %23
$ = %24
% = %25
& = %26
= = %3D
? = %3F
: = %3A

Example:
Password: pass@word#123
URL-encoded: pass%40word%23123

Connection string:
postgresql://taskuser:pass%40word%23123@host:5432/task_manager
