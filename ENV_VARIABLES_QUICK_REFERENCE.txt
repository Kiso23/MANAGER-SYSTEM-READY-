                    ENVIRONMENT VARIABLES - QUICK REFERENCE
================================================================================

🔧 BACKEND ENVIRONMENT VARIABLES (Required)
================================================================================

DATABASE_URL
├─ Purpose: PostgreSQL database connection
├─ Format: postgresql://user:password@host:5432/database
├─ Example: postgresql://taskuser:mypass@db.example.com:5432/task_manager
└─ Get from: Platform dashboard (Render, Railway, Heroku, AWS, etc.)

JWT_SECRET
├─ Purpose: Secret key for JWT token signing
├─ Format: 32+ character random string
├─ Example: 797a3e0baed7dcd24c3ef3198db72bf356a5c80aa7a8a050a0793030c59f1137
├─ Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
└─ Security: Keep secret! Never commit to git!

NODE_ENV
├─ Purpose: Environment type
├─ Value: production
└─ Why: Enables production optimizations

PORT
├─ Purpose: Server port
├─ Value: 5000
└─ Note: Most platforms auto-assign

================================================================================

🔧 BACKEND ENVIRONMENT VARIABLES (Recommended)
================================================================================

CORS_ORIGIN
├─ Purpose: Allowed frontend domain
├─ Format: https://your-frontend-domain.com
├─ Example: https://task-manager-ui.onrender.com
└─ Why: Security - only allow requests from your frontend

LOG_LEVEL
├─ Purpose: Logging verbosity
├─ Values: error, warn, info, debug
└─ Default: info

================================================================================

🔧 BACKEND ENVIRONMENT VARIABLES (Optional)
================================================================================

DATABASE_SSL
├─ Purpose: Enable SSL for database
├─ Values: true or false
└─ When: Required by some platforms (DigitalOcean, Supabase)

RATE_LIMIT_WINDOW_MS
├─ Purpose: Rate limiting window
├─ Default: 900000 (15 minutes)
└─ Example: RATE_LIMIT_WINDOW_MS=900000

RATE_LIMIT_MAX_REQUESTS
├─ Purpose: Max requests per window
├─ Default: 100
└─ Example: RATE_LIMIT_MAX_REQUESTS=100

SENTRY_DSN
├─ Purpose: Error tracking
├─ Format: https://key@sentry.io/project-id
└─ Optional: Only if using Sentry

================================================================================

🎨 FRONTEND ENVIRONMENT VARIABLES (Required)
================================================================================

VITE_API_URL
├─ Purpose: Backend API base URL
├─ Format: https://your-backend-url/api/v1
├─ Example: https://task-manager-api.onrender.com/api/v1
├─ Important: Must include /api/v1 at the end
└─ Get from: Backend service URL from your platform

================================================================================

🎨 FRONTEND ENVIRONMENT VARIABLES (Optional)
================================================================================

VITE_ANALYTICS_ID
├─ Purpose: Google Analytics tracking
├─ Format: G-XXXXXXXXXX
└─ Optional: Only if using Google Analytics

VITE_SENTRY_DSN
├─ Purpose: Error tracking for frontend
├─ Format: https://key@sentry.io/project-id
└─ Optional: Only if using Sentry

VITE_LOG_LEVEL
├─ Purpose: Frontend logging level
├─ Values: error, warn, info, debug
└─ Default: info

🚀 AWS SETUP
================================================================================

Create .env file:
cat > /home/ec2-user/task-manager/.env << 'EOF'
DATABASE_URL=postgresql://taskuser:password@task-manager-db.abc123.us-east-1.rds.amazonaws.com:5432/task_manager
JWT_SECRET=797a3e0baed7dcd24c3ef3198db72bf356a5c80aa7a8a050a0793030c59f1137
NODE_ENV=production
PORT=5000
CORS_ORIGIN=https://your-frontend-url
EOF

Or use AWS Systems Manager Parameter Store:
aws ssm put-parameter --name /task-manager/prod/database-url --value "postgresql://..." --type String
aws ssm put-parameter --name /task-manager/prod/jwt-secret --value "797a3e0baed7dcd24c3ef3198db72bf356a5c80aa7a8a050a0793030c59f1137" --type SecureString

🔒 SECURITY BEST PRACTICES
================================================================================

✅ DO:
├─ Store secrets in environment variables (never in code)
├─ Use strong random values for JWT_SECRET
├─ Use different secrets for different environments
├─ Rotate secrets periodically (every 6-12 months)
├─ Keep DATABASE_URL secure
├─ Use HTTPS for CORS_ORIGIN
└─ Enable DATABASE_SSL when available

❌ DON'T:
├─ Commit .env files to git
├─ Share secrets via email or chat
├─ Use weak or predictable secrets
├─ Use same secret across environments
├─ Log or expose secrets
├─ Hardcode secrets in code
└─ Share DATABASE_URL publicly
